# 证据与应用对照

研究支持一种机制，不代表已经验证本手册的每个操作步骤。这张表帮助读者区分机制、演算和生活设计。

| 主题 | 主要依据 | 应用推导 | 应保留的条件 |
|---|---|---|---|
| 目标与取舍 | [S01](sources.md#s01) | 分开目标、底线和偏好 | 分类是整理方法，价值由当事人决定 |
| 继续或停止 | [S01](sources.md#s01) | 分开过去、可回收资源与未来 | 历史仍提供信息，未来承诺后果不能删去 |
| 小步试错 | [S04](sources.md#s04) | 按关键未知分阶段投入 | 小试验不能自动外推，试验也有成本 |
| 风险承受 | [S10](sources.md#s10)及期望值演算 | 先查必要责任，再看平均结果 | 猜测概率不是实测，类比不是配置建议 |
| 信息判断 | [S07](sources.md#s07)、[S09](sources.md#s09) | 追溯样本、共同来源与行动价值 | 多次转述不等于独立验证 |
| 个人实验 | [S04](sources.md#s04)、[S05](sources.md#s05) | 比较任务、记录返工、预设标准 | 前后变化不能自动识别因果 |
| 执行与习惯 | [S02](sources.md#s02) | 降低准备摩擦、允许恢复 | 不规定统一天数、不保证效果 |
| 消费与订阅 | [S01](sources.md#s01)、[S02](sources.md#s02)、[S11](sources.md#s11) | 检查总承诺、日期和使用价值 | 费用与取消条件以实际条款为准 |
| 家庭分工 | [S08](sources.md#s08)、[S12](sources.md#s12) | 看见协调、讨论恢复与复核 | 家庭不是公共草地，工资不能代替同意 |
| 合作 | [S06](sources.md#s06) | 明确成果、变化、决定与退出 | 不把全部关系计件化，不是法律合同 |
| 现金流 | [S11](sources.md#s11) | 按日期排账、标出缺口 | 不推荐统一产品或储蓄月数 |
| 时间与兴趣 | [S01](sources.md#s01)、[S03](sources.md#s03) | 保护恢复与乐趣，允许暂停 | 收入不是唯一价值，情绪不是全部证据 |

## 完整案例的检查重点

- **换工作：** 同口径到账、重复计费检查、一次费用回收、时间原单位、照护底线和回退安排。
- **工具升级：** 同一交付边界、端到端时间、使用频次、质量维护与实际导出链路。
- **家庭现金流：** 逐日余额、期初与新增结余、必要付款缺口、额外冲击、未确认安排不当作已解决。

案例人物和数字均为虚构，用于展示带条件的推理，不提供通用最优答案。欢迎指出具体事实、计算或推导错误，提供可定位的原始来源；不同生活价值的取舍应与事实错误分开讨论。

## v1.1 理论工具与应用边界

| 理论与来源 | 研究支持的机制或概念 | 本手册新增的应用 | 不据此声称 |
|---|---|---|---|
| 参考类预测 S13 | 用可比历史结果校正预测 | 个人用时样本、两周报告案例 | 五个样本提供精确成功概率 |
| 实施意图 S14 | 预先连接情境线索与行动 | 账单整理与中断恢复 | 一句话解决条件不足，固定天数养成习惯 |
| 信息价值 S15、S09 | 信息改善后续选择的期望价值 | 兼容性测试的离散状态算例 | 假设概率等于真实产品表现 |
| 不可逆投资 S16 | 提前承诺与等待信息的权衡 | 100 元试用与等待代价 | 所有决定都应该推迟 |
| 比较优势 S17 | 比较相对机会成本 | 两项任务分工与公平讨论 | 速度决定人的价值或家庭角色 |
| 匹配理论 S18 | 稳定配对与规则影响分配 | 求职三栏清单 | 现实招聘都符合教材模型 |

新增算例均为原创教学假设。短译只节选可定位的一句，作者稿页码、出版年与上传年在[参考来源](sources.md)分别标明。
