# 普通人生活决策手册

**把经济学与决策研究用到消费、时间、学习、工作和共同生活里。**

买东西总犹豫，学了很久不甘心停，日程排满仍然焦虑，或者面对换工作、搬家和家庭分工，不知道从哪里比较？这份中文手册从具体问题开始，帮助你看清代价、检查证据、保住必要安排，并根据新信息调整。

你不需要先读完经济学教材。这里有 **8 篇决策方法、15 篇生活场景、3 篇完整案例和 7 份可复制模板**，另附入门路线、生活安排、来源与证据对照。研究用来解释机制，生活应用保留个人目标与现实条件。

## 可以带走的几种做法

1. **先说明要保住什么。** 让底线筛选方案，再比较可交换的偏好。
2. **给替代方案一个位置。** 不买、修好、缩小和等待，都有各自代价。
3. **从未来决定下一笔投入。** 过去用于学习，可回收资源继续计入。
4. **让承诺随信息增加。** 能安全尝试的事小步验证，难回头的事核查关键条件。
5. **检查失败是否切断必要生活。** 平均划算不等于这次承担得起。
6. **把执行放回真实环境。** 减少准备摩擦，也允许条件变化时修改规则。
7. **让休息、陪伴和兴趣直接有价值。** 它们不需要通过增收证明自己。
8. **给判断留复核入口。** 写下什么新信息会让你改主意。

这些是研究启发的生活设计方法。具体选择取决于目标、资源和受影响的人，资源与制度约束也不能全部靠个人优化消除。

## 阅读与使用

直接在 GitHub 阅读，或下载文件夹在 Obsidian 中打开。正文使用标准 Markdown 相对链接，不依赖插件。仓库提供 Docsify 静态阅读入口，部署方法见[贡献指南](CONTRIBUTING.md)。

小决定选一条有用的问题即可。重要选择可用[一页决策卡](docs/05-可复制模板/01-一页决策卡.md)，不需要把每次吃饭、聊天和休息都变成项目。

教学人物与数值均为假设；研究与应用关系见[阅读说明](docs/00-开始阅读/03-怎样读研究与建议.md)。重大财务、医疗、法律或安全后果需结合真实资料、当地规则与适当专业支持。
