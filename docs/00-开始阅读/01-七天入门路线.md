# 七天入门路线

每天只处理一个真实小问题。七天是阅读安排示例，不是形成习惯、改善收入或完成生活改变的科学期限。时间紧时，可以把它拉长；也可以直接从眼前的问题开始。

| 次序 | 阅读 | 一个行动 |
|---|---|---|
| 第一天 | [目标与底线](../01-决策方法/01-先说清目标与底线.md) | 写下一个决定最想改善什么、不能破坏什么 |
| 第二天 | [未来代价](../01-决策方法/02-只比较从现在开始的代价.md) | 把过去投入、当前可回收资源和未来成本分开 |
| 第三天 | [消费场景](../02-日常生活/01-买东西先找真实使用场景.md) | 给购物清单补一个真实使用场景与替代方案 |
| 第四天 | [时间与恢复](../02-日常生活/04-安排时间也要安排恢复.md) | 说明一个新增任务将挤掉什么 |
| 第五天 | [现金流](../03-重要选择/03-现金流先保证必要付款不断.md) | 按日期排出几次必要付款与确定入账 |
| 第六天 | [可比较实验](../01-决策方法/06-把生活小实验做得可比较.md) | 为一项低风险试用写下范围、标准与停止条件 |
| 第七天 | [每周复盘](../05-可复制模板/04-每周复盘.md) | 保留一件有价值的事，缩小一件不合适的事 |

## 怎样判断这轮阅读有没有用

你是否更清楚自己真正比较的是什么？是否提前发现一个原先遗漏的成本或约束？是否知道需要什么新信息才会改变判断？这些变化比“看完多少理论”更接近本手册的目的。

一个决定暂时没有结果，也可以有进展：你排除了不可行方案，保住了必要责任，或停止了没有新增信息的搜索。不要为了交作业，在信息不足时强行做出重大承诺。
