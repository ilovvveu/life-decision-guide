# 双向选择还要看对方与规则

检索词：匹配理论、双向选择、稳定匹配、招聘、matching

找岗位时，你可以把公司排成一张愿望清单，但公司也在筛选候选人，名额与录用时限还会影响结果。匹配理论提供一个视角：选择结果由双方偏好与分配规则共同形成。

## 一个足够小的模型

在最简单的一对一模型中，双方各有偏好排序。如果有一对尚未配在一起的人，都更愿意选择对方而不是当前对象，他们就构成阻挡配对。不存在这种配对，称为稳定匹配。这个概念依赖模型的偏好、可接受对象与配对规则。[S18](../../references/sources.md#s18)

**虚构教学例子。** 两名申请人甲、乙和两个岗位 A、B。甲偏好 A 再 B；乙偏好 B 再 A。A 偏好乙再甲；B 偏好甲再乙。甲去 A、乙去 B 时，申请人都得到首选；甲去 B、乙去 A 时，岗位都得到首选。两种结果在这个简化模型下都稳定，却照顾了不同一方。

这说明“稳定”不能直接翻译成“所有人最满意”或“唯一公平结果”。官方介绍也讨论了延迟接受算法中，提议权可能带来的分配差异，结论不能无条件推广到任意招聘流程。

## 普通人可以带走什么

先检查可接受条件，再分别记录自己的排序、对方的筛选标准，以及名额、期限、候补和退出规则。对方尚未回复，与自己已经有可接受的正式机会，属于不同状态。决策表应保留这些区别。

愿望清单可以帮助筛选，了解对方需要的工作样例、能力证据与排班条件，可以帮助准备。被拒绝不等于一个人的整体价值低，它还可能反映特定名额与条件是否匹配。

## 不把模型变成万能策略

现实求职会有薪酬协商、信息差异、变化的需求和不同时限，通常并不完整运行某一种匹配算法。不能据此宣称“主动一方永远占优”，也不能把某个平台的真实规则猜成教材模型。先核实实际流程，再考虑怎样行动。

这篇提供分析视角，不为择偶、育儿或职业选择规定统一排序；人的意愿、权利和关系不能被一张名次表替代。

**现在可做的一步：**在[换工作比较](../03-重要选择/01-换工作比较收入时间与回退空间.md)旁增加三栏：“我需要什么、对方需要什么、实际规则是什么”，把确定机会与愿望分开。
