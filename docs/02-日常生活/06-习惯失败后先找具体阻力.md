# 习惯失败后先找具体阻力

<!-- guide-meta:start -->
标签： #场景/学习 #场景/时间 #理论/自我控制 #理论/实施意图 #阶段/开始行动

检索词：拖延、三分钟热度、坚持不了、习惯中断
<!-- guide-meta:end -->
计划执行三天就中断，很容易得出“我就是坚持不了”的结论。这个结论太大，无法告诉你下次改哪里。把失败缩小成一个发生在某时某地的事件，才可能找到可调整的条件。

## 记录没发生的那一步

不是记“今天又失败”，而是记：“原定晚饭后练习，临时开会结束已很晚，资料还没准备好。”在这个描述里，时间冲突、任务准备与疲劳分别可处理。单纯增加惩罚，可能一个也没解决。

也要允许另一个解释：这个目标其实不重要，或者本来就是别人希望你做的。放弃不认同的目标，与放弃自己重视的事情，需要不同的讨论。

## 把第一次行动缩小

假设你想每周整理一次支出，却总因为“要把几个月全部补齐”而不开始。可以先只整理最近一天，确认分类方法能用，再决定是否扩大。小动作的价值是打通流程，不是靠每天一点点就保证完成所有长期目标。

如果关键障碍是任务缺乏反馈，缩小规模仍不够；你还需要知道完成得怎样。要让行动后有可见结果，例如练习后能独立完成一个步骤，而不只是打卡图标变绿。

## 做一个失约后的恢复安排

漏一次后，不必通过加倍任务偿还。可以重新执行最低可行的一步，再判断是否调整时间。补偿过大容易把一次意外变成更难进入的下一次。

与别人约定的责任则要及时沟通。个人练习可以自由缩小，共同交付不能在未说明的情况下自行取消。环境设计不能成为忽视对方安排的理由。

## 看趋势时保留成本

完成次数增加，却越来越疲劳、影响必要责任，方案仍可能不合适。可以同时观察能否完成、完成后是否值得、是否能在现实生活中持续。评价生活安排，不应只保留最容易计数的那一项。

本篇由自我控制与激励思想推导出排障方法，没有使用“固定多少天养成习惯”之类统一期限。[S02](../../references/sources.md#s02)、[S06](../../references/sources.md#s06)
