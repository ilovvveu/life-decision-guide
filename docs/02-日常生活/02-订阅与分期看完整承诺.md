# 订阅与分期看完整承诺

“每天只要几块钱”让价格容易接受，却没有说明你最终答应支付多少。订阅和分期购买前，应同时看总额、付款日期、取消条件，以及收入变化后仍然必须履行的部分。

## 月费小，不等于总成本小

假设工具按月六十元，年付五百元。若你能取消月付，且只会使用四个月，月付共二百四十元；年付在这个使用时长下反而更贵。只有在同样需要全年服务、功能相同、其他条件接近时，五百元才相对七百二十元便宜。

月付还可能有试用后的自动续费、最低使用期或提前终止费用。别根据“按月显示”推断“随时取消”；以实际确认页面和条款为准。

## 把费用分成三层

第一层是账单金额；第二层是为了使用它还要买的配件、服务和时间；第三层是退出成本，包括迁移数据、失去旧格式和重新学习。一个低价订阅若承担了全部核心资料，第三层可能逐渐变大。

提前试一次导出和恢复，比看到“支持导出”四个字更有信息。记录实际导出的内容、格式以及能否在其他地方使用，不要把按钮存在当作迁移已经成功。

## 分期尤其要分开总价与现金流

总价相同的两种付款方式，也可能在手续费、时间安排和逾期后果上不同。先写出每期金额与日期，再核对全部费用、取消与提前结清条件。不要用“每期看起来能付”替代对未来几个月必要付款的检查。

如果只是把自己原本不打算承担的支出拆小，分期并没有让物品更便宜。若付款安排用于解决真实的时点问题，也应确认它没有依赖尚未确定的奖金或订单。

## 给续费一次重新选择

每次续费前，问“如果今天没有这个订阅，我会按现在的价格重新开通吗？”同时查看过去一段时间的真实使用和替代成本。曾经好用，不代表现在必须继续；目前很少打开，也不意味着存储或备份价值为零。
