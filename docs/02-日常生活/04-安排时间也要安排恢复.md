# 安排时间也要安排恢复

<!-- guide-meta:start -->
标签：#场景/时间 #理论/机会成本 #阶段/明确目标

检索词：休息、疲劳、太忙、时间管理、恢复
<!-- guide-meta:end -->
日程表里每个空格都塞满了学习和工作，执行时却不断延期。这里可能有两个遗漏：事情之间存在准备和收尾，而人也需要从上一件事中恢复。可用时间不等于日历上尚未占用的分钟数。

## 先看一周怎样实际发生

不必全天精确打点。选几天粗略记录工作、通勤、必要家务、照护、娱乐和睡眠安排，尤其记录临时事情从哪里挤出了时间。记录的用途是理解约束，不是寻找每一分钟的罪证。

有些看似碎片的空闲，适合休息和小事务，不一定适合需要连续注意力的任务。如果你只能找到四段十五分钟，就不要把它们自动视为一小时完整创作时间。

## 比较新增任务挤掉了什么

答应每周多做四小时项目，就需要说明这四小时从哪里来。它可能挤掉无目的刷屏，也可能挤掉你已经不足的休息或陪伴。代价不同，结论也会不同。

假设周末有六小时自由时间，一项练习安排四小时，却还要准备一小时、整理一小时。它已占满全部窗口。再为自己排一次社交活动，意味着发生冲突，而不是计划突然变得更有雄心。

## 恢复可以是你直接重视的目标

休息不必先证明能提高工资才值得保留。你可以因为喜欢安静、想陪家人或单纯疲劳而选择休息。也应留意有些娱乐并没有达到预期的放松效果；可以比较结束后的感受与挤掉的其他活动。

不要用单一时长目标评价所有休息方式。照护责任、健康状况和工作节奏会改变安排，需要按照自己的现实条件调整。

## 用弹性代替满格

每周只选少数真正希望完成的事，预留处理意外的空间。具体留多少取决于生活波动，不存在本手册规定的统一百分比。若突发任务总是侵占同一人的恢复时间，应讨论责任分配，而不只是要求那个人更高效。

基础依据是时间的机会成本。缓冲、恢复与连续时间的安排属于生活设计建议，不是关于睡眠时长或健康干预的处方。[S01](../../references/sources.md#s01)
