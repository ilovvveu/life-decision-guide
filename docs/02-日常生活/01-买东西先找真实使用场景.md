# 买东西先找真实使用场景

<!-- guide-meta:start -->
标签： #场景/消费 #理论/机会成本 #理论/前景理论 #阶段/比较方案

检索词：冲动消费、买不买、剁手、打折、购物
<!-- guide-meta:end -->
一件商品的宣传通常展示拥有之后的理想生活：更整洁、更专业、更自律。购买前值得补上的，是它进入你现在生活后的具体安排。它会在什么时候被用到，替代什么，需要谁来维护？

## 从最近发生的需求开始

回想过去一个月：你有多少次因为缺少它而明显受阻，当时怎样解决，现有办法哪里不够。已经反复出现的问题，比“以后也许会用到”的想象更适合作为起点。

有些购买本来就是为了乐趣，不必伪装成生产力投资。只要它没有挤掉你更想保留的安排，“我喜欢它，愿意为此支付”可以是完整的理由。需要警惕的是用不存在的工作收益，为超出承受能力的支出找解释。

## 把替代方案放上桌

不买、借用、租用、二手、维修现有物品，往往与购买新品一样值得比较。替代并非必然更便宜：租借可能需要押金、往返和检查，二手需要承担成色和售后不确定性。应比较它们解决同一个需求的完整代价。

假设一台设备售价三千元，保守估计转售能回收一千元，配件和维护五百元。若使用一百次，不计资金时间价值的净成本为二十五元一次；若只用十次，就是二百五十元一次。转售价与使用次数都是假设，不能当作必然兑现的折扣。

## 给调查设置终点

先列三项必须满足的要求，筛掉不合适的，再比较少量候选。对已经足够合适的低风险物品，继续比较几十个参数可能不值得。对难退、金额大的物品，则应把核查集中在最可能造成后悔的条件，如噪音、尺寸、维修和兼容。

看到“限时”先核对截止是否真实。可以错过一次折扣，换取更清楚的需求；也可以因确有刚需迅速购买。等待的意义是减少冲动，不是建立“越晚买越理性”的新规则。

## 下单前留下四行

我要解决的具体问题是……；现有办法的问题是……；这次最多能承受的总费用是……；买后一个月，我会通过……判断它有没有用上。
