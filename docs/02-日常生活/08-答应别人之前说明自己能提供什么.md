# 答应别人之前说明自己能提供什么

为了不让人失望，你答应“有事随时找我”。事情真正发生后，自己难以承担，对方又已形成期待。明确范围往往比宽泛承诺更容易维持关系。

## 把愿意和能够分开

你可以真心想帮忙，同时只有一小时、缺少专业能力，或不能承担失败后果。先表达关心，再说明可提供的具体帮助，例如一起梳理选项、介绍公开资源、陪同一次沟通。无需为了证明善意而承诺全部问题。

也可以直接拒绝。拒绝的理由不一定要经过对方认可，尤其当请求会破坏必要责任或个人安全。对普通的互助则可讨论替代时间和范围。

## 检查一次答应产生的后续责任

帮忙修一次表格，是否意味着以后长期维护？代为保管物品，谁负责损坏或无人取回？给建议，是否被理解成你保证结果？把这些误解提前说开，比发生问题后争论“我当时不是这个意思”更省力。

假设你可以帮朋友检查两页简历，却没有时间代写整份材料。可以说：“这周我能看两页，主要反馈结构和清楚程度；岗位事实和最终提交由你确认。”范围清楚，双方更容易判断安排是否合适。

## 关系不必逐笔结算

互助可以基于亲近、关心和共同价值，不需要把每一小时标价。但长期单方面付出产生疲劳时，也不应被“朋友之间别计较”堵住讨论。看的是一段时间中的可持续性，而不只是单次交换是否对等。

重复合作重视未来关系，但“我们以后还要相处”也不应成为要求一方无条件承担的工具。适当边界能让承诺更可信，不能保证所有人都会满意。

## 一个简短的承诺格式

我能提供……；大约到……为止；我做不到的是……；如果情况变化，我们通过……重新确认。对方可以据此决定接受、调整或另找办法。

这是从机会成本、合作范围和不完全约定推导出的沟通方法，不是评价亲密程度的公式。[S01](../../references/sources.md#s01)、[S06](../../references/sources.md#s06)
