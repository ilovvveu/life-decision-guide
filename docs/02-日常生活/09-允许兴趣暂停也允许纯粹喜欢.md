# 允许兴趣暂停也允许纯粹喜欢

买过器材、学过一段时间，兴趣慢慢变淡了。有人劝你坚持才有收获，也有人劝你立即止损。先看这项活动现在提供的价值，以及继续参与需要占用什么，才能区分倦怠、阶段变化和不再喜欢。

## 兴趣不需要通过收入考试

画画、钓鱼、做模型和阅读，可以因为过程本身值得而存在。把所有爱好都变成副业，会增加交付、运营和比较的责任。你可以选择进阶，也可以选择保持业余，不必让盈利证明活动的正当性。

同样，已经付费也不要求你永远喜欢。器材的购买价无法追回，但今天的转售价、保管空间与维护时间还会影响选择。保留、出售、借给别人或暂时收起，都是可比较的方案。

## 用一个小恢复机会区分原因

如果是准备复杂，可以先做一次低门槛版本；如果是连续任务太累，可以暂停一段时间；如果是不喜欢公开比较，可以改成私人练习。观察你是否重新获得想要的体验，而不是只看有没有完成原定数量。

小尝试不应变成新的强迫。已经很清楚不想继续，也没有影响别人责任时，可以直接结束，不需要再证明一次。

## 小心“放弃就证明我不行”

我们可能把退出理解成失去某种身份，因而继续花钱维持。可以把问题改成：“在当前阶段，这项活动是否值得我接下来的时间？”这允许你评价安排，而不是给整个人下结论。

但遇到学习平台期时也别只靠瞬时情绪决定。若长期目标仍重要，可能需要改变练习或反馈。关键是未来价值是否还存在，而不只是过去成绩是否好看。

## 选择一个温和的收尾

保存你在乎的作品，处理共用或借来的物品，说明已经答应的活动怎样安排。这样暂停不必意味着抹掉整个阶段。以后条件改变，也可以重新开始。
