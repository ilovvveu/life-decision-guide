# 给信息消费一个停止条件

为了选一件东西看了一晚上测评，问题反而更多了。每看一条信息都像在认真准备，但真正影响选择的条件，可能早已没有变化。值得管理的是信息对下一步行动的帮助。

## 先写出未解决的问题

把“我再了解一下”改成“我需要确认它能否在我的设备上导出通用文件”。具体问题可以决定去哪找、怎样验证以及什么时候结束。没有这个步骤，搜索很容易顺着推荐内容不断扩展。

信息也有其他用途：娱乐、欣赏、社交、获得陪伴。可以享受这些用途，不必统统解释成学习。问题在于你本想完成选择，却在没有察觉时切换了目标。

## 证据的价值取决于能否改变选择

假设你已排除价格超过预算的产品，继续查看昂贵旗舰的性能，对眼下选择可能帮助很小。若某个参数会决定必要功能能否使用，则一次准确验证可能比几十篇泛评更重要。

先问：“得到肯定或否定答案后，我会分别做什么？”两种答案都不改变行动，当前的调查优先级通常可以降低；若主要价值是安心，也可以给安心设置合理成本。

## 分开浏览与决定

想自由逛可以给自己一段没有任务的时间；真正要决定时，则回到少量候选、底线条件和截止点。这样不必禁止好奇心，也能避免所有浏览都侵入计划。

截止点可以是“确认三项必要条件，并比较两种可行方案”。这只是当前任务的启发式规则；金额、可逆性和风险不同，需要的核查强度也不同。若关键问题仍无答案，应记录未知，而不是强行宣布调查完成。

## 保留一份简短结论

用三句话记录：“我选择什么”“最重要的依据是什么”“哪条新信息会让我重看”。下次出现类似宣传，可以先看它是否真的增加了新信息，而不是从头再看一遍全部内容。

本篇的概率和证据思路可参见[S09](../../references/sources.md#s09)；停止条件、浏览分流和记录方式是本手册的应用设计。
