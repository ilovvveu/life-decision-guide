# 每周复盘

找一个不打断必要休息的时间，简短写几行即可。目的是改善下周的安排，不是追究每一分钟有没有创造价值。

## 这一周实际怎样发生

- 一件符合自己目标的事：
- 一件没有按预期发生的事：
- 它发生时的具体条件，而非对自己的总评价：
- 哪段休息、陪伴或兴趣值得保留：

## 区分过程与结果

- 结果顺利，是否可能包含运气或外部变化：
- 结果不顺，当时的信息与程序是否仍合理：
- 哪个判断的证据变了：
- 哪项责任或成本此前没被看见：

## 下周只改少量事情

- 保留：
- 停止或缩小：
- 一个可以执行的小调整：
- 为它让出的具体时间或其他活动：
- 如果再次被打断，怎样恢复最低可行一步：

## 需要共同讨论的安排

- 影响谁：
- 需要取得什么信息或同意：
- 怎样联系，何时复核：

如果每次复盘都变成一份越来越长的欠账，可以删去不再重要的目标，或降低记录频率。一次复盘也可以只得出“这周需要更多恢复”。
