# 信息与建议判断卡

适合一条会影响购买、学习、工作或转发的建议。一般娱乐内容不必逐条审查；把精力留给会改变承诺的判断。

## 它究竟声称什么

- 具体结论，避免只写标题：
- 适用人群、时间、条件：
- 是事实、研究结论、个人经验，还是推广承诺：
- 发布者是否从你的采纳中获得收益：

## 证据怎样产生

- 最初来源与能定位的段落：
- 样本是谁，失败或未参与者是否可见：
- 数据是否支持因果，还是只说明同时发生：
- 多个报道是否引用同一个原始来源：
- 与我现实条件最重要的差异：

## 它改变了什么

- 我原先的判断：
- 这条信息新增的部分：
- 仍然可能成立的其他解释：
- 哪条观察会使我改变判断：
- 现在可采取的低成本下一步：

## 暂时结论

采纳、部分采纳、保留或拒绝：____。理由：____。何时值得重新看：____。

无法估计概率时，写清未知即可。不要为了填写卡片而编造精确百分比。
